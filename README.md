# PowerMangai — PowerPoint ショートカット練習アプリ

PowerPoint のショートカットキーを覚えるためのデスクトップアプリ（Electron）です。
**マウスは使えません。** お手本のスライド（画像）を見ながら、キーボードだけで同じスライドを再現する練習をします。

## 起動方法

```bash
npm install
npm start
```

## 練習の流れ

1. **F8** で課題を選ぶ（8 題・★1〜★4）。右側にお手本のスライドとヒントが表示されます。
2. キーボードだけでお手本と同じスライドを作る。
3. **F9** で採点。違うところと、直すためのショートカットが表示されます。自己ベストは課題ごとに記録されます。

自分で用意した画像（PowerPoint のスライドのスクリーンショットなど）をお手本にすることもできます。
**Alt → Y → I** で画像を読み込み、**F9** で現在のスライドとの一致度（%）を表示します。

画面右下には、押したショートカットとその操作名が表示されます。割り当てのないキーを押すと赤く表示されます。
上部には経過時間・キーを押した回数・マウスを使おうとした回数が表示されます。

## できること

PowerPoint for Windows の主な機能を、同じショートカット・KeyTips で操作できます。

- **文字**: 文字ごとの書式（フォント・サイズ・色・太字・斜体・下線・取り消し線・上付き / 下付き・蛍光ペン・文字の間隔）、箇条書き・段落番号・インデント・行間・配置、縦書き、ハイパーリンク、記号の挿入、検索と置換
- **図形**: 35 種類の図形、塗りつぶし・枠線（太さ・線の種類・矢印）・影・透明度、クイック スタイル、図形の変更、グループ化、配置と整列、回転・反転、選択ウィンドウ、代替テキスト、図形の書式設定
- **表・図・グラフ**: 表（行・列の挿入 / 削除、タイトル行・縞模様、セルの塗りつぶし）、画像、グラフ（集合 / 積み上げの縦棒・横棒、折れ線、面、円、ドーナツ。データの編集、タイトル・凡例・データ ラベル・目盛線、色の変更）
- **スライド**: レイアウト、テーマ（独自テーマの読み込みを含む）、背景、スライドのサイズ、ヘッダーとフッター、非表示スライド、ノート、スライド一覧、ズーム・グリッド・ガイド
- **画面切り替え・アニメーション**: 効果・方向・期間・開始のタイミング、アニメーション ウィンドウ、自動切り替え
- **スライドショー**: F5 / Shift+F5、発表者ビュー（Alt+F5）、B / W、番号+Enter、Ctrl+S（すべてのスライド）、H（非表示スライド）、リンク（Tab / Enter）
- **ファイル**: `.pptx` の読み込み・保存（PowerPoint・LibreOffice と相互に開ける）、独自形式（`.pmg.json`）、PDF・印刷、PNG 書き出し、未保存の変更の確認
- **クイック アクセス ツール バー**: Alt → 1（上書き保存）/ 2（元に戻す）/ 3（やり直し）

## 主なショートカット（PowerPoint for Windows と同じ）

| 操作 | キー |
| --- | --- |
| オブジェクトの選択 | Tab / Shift+Tab、Ctrl+A、Esc で解除 |
| 文字の編集 | 選択中に文字を入力、Enter / F2 で開始、Esc で終了 |
| 移動 / 微調整 | 矢印 / Ctrl+矢印 |
| サイズ変更 | Shift+矢印 / Ctrl+Shift+矢印 |
| 回転 | Alt+← / → （15°）、Ctrl+Alt+← / →（1°） |
| 太字・斜体・下線 | Ctrl+B / I / U |
| 文字揃え | Ctrl+L / E / R / J |
| フォント サイズ | Ctrl+Shift+> / <（Ctrl+] / [） |
| フォント ダイアログ | Ctrl+T |
| 書式のコピー / 貼り付け | Ctrl+Shift+C / V |
| グループ化 / 解除 | Ctrl+G / Ctrl+Shift+G |
| 最前面 / 最背面 | Ctrl+Shift+] / [ |
| 複製 | Ctrl+D |
| ハイパーリンク | Ctrl+K |
| 検索 / 置換 | Ctrl+F / Ctrl+H |
| 元に戻す / やり直し・繰り返し | Ctrl+Z / Ctrl+Y・F4 |
| 新しいスライド | Ctrl+M、Ctrl+Enter（最後のプレースホルダーから） |
| スライド一覧 ↔ 編集領域 | F6（一覧では ↑↓ で移動、Ctrl+↑↓ で並べ替え、Delete で削除） |
| スライドショー | F5（最初から）/ Shift+F5（現在から）/ Alt+F5（発表者ビュー） |
| 保存 / 開く / 新規 / 印刷 | Ctrl+S / Ctrl+O / Ctrl+N / Ctrl+P、F12 で名前を付けて保存 |

### KeyTips（Alt キー → 文字キー）

Alt キーを押して離すと、リボンのキーが表示されます（Alt+H のように押したままでも可）。Esc で 1 階層戻ります。

| 操作 | キー |
| --- | --- |
| テキスト ボックス / 図形 / 表 / 画像 / グラフ | Alt → N → X / S → H / T / P / C |
| 図形の塗りつぶし / 枠線 | Alt → H → S → F / Alt → H → S → O |
| フォントの色 / サイズ / フォント | Alt → H → F → C / F → S / F → F |
| 蛍光ペン / 文字の間隔 | Alt → H → T → H / F → T |
| 配置（左・中央・右・上・中・下） | Alt → H → G → A → L / C / R / T / M / B |
| 前面・背面へ | Alt → H → G → R / F / K / B |
| 90° 回転 | Alt → H → G → O → R / L |
| 幅 / 高さを数値で指定 | Alt → J → D → W / H |
| 表のレイアウト / テーブル デザイン | Alt → J → L / Alt → J → T |
| グラフのデザイン | Alt → J → C（D: データの編集、C: 種類の変更、A: グラフ要素、H: 色の変更） |
| 画面切り替え / アニメーション | Alt → K / Alt → A |
| 新しいスライド（レイアウト選択） | Alt → H → I |

すべてのショートカットは **F1** で一覧表示できます（文字を入力して絞り込み可能）。

### 練習用（このアプリ独自）

| 操作 | キー |
| --- | --- |
| 課題を選ぶ | F8（Alt → Y → C） |
| 採点 | F9（Alt → Y → S） |
| お手本の表示 / 非表示 | F11（Alt → Y → H） |
| ヒントの表示 / 非表示 | Alt → Y → T |
| お手本画像を読み込む | Alt → Y → I |
| 課題をやり直す | Alt → Y → R |

## 制限事項

- 本家 PowerPoint のすべての機能を再現しているわけではありません。`.pptx` を読み込んだとき、対応していない内容（SmartArt・動画・結合したセルなど）は一覧で表示され、近い形で読み込むか省略します。
- グラフのデータは、アプリ内の「データの編集」ダイアログで編集します（Excel は使いません）。

## 開発

```
main.js / preload.cjs   Electron のメイン プロセスとプリロード
src/core/               DOM に依存しないロジック（モデル・編集コマンド・ショートカット表・KeyTips・採点・課題・グラフ・.pptx の読み書き）
src/ui/                 画面（描画・ダイアログ・アプリ本体）
test/                   単体テスト（node:test）
test/e2e/               ブラウザで実際にキー操作する E2E テスト（Playwright）
```

```bash
npm test                 # 単体テスト
npm run test:e2e         # E2E テスト（Chromium が必要。CHROMIUM_PATH で指定可）
npm run serve            # ブラウザで動作確認（http://127.0.0.1:8080/）
xvfb-run -a node scripts/smoke-electron.cjs   # Electron 実機の起動確認
```
